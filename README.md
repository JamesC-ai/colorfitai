# ColorFitAI

Private browser-local personal color sampling and shopping palette generator.

The production build includes 15 focused SEO pages, policy and support pages, a 19-URL sitemap, and IndexNow submission automation. Photos stay in the browser, and results are shopping references rather than identity, health, age, ethnicity, or attractiveness judgments.

## Commands

- `npm test`
- `npm run dev`
- `npm run deploy`
- `npm run indexnow`
